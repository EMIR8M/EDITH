# 👾 دستیار هوش مصنوعی EDITH
## 📝 معرفی EDITH
ادیت یک دستیار صوتی هوشمند و اوپن‌سورسه که با پایتون ساخته شده تا کارهای روزمره‌تون رو ساده‌تر و جذاب‌تر کنه. چه بخواید با هوش مصنوعی گپ بزنید، چه نیاز داشته باشید دستورات سیستمی‌تون رو فقط با صدا کنترل کنید، ادیت اینجاست تا کمک‌تون کنه. این پروژه برای من شروع یه ماجراجویی جذاب توی دنیای AI بود و خیلی خوشحال میشم اگه شما هم امتحانش کنید و نظرتون رو بهم بگید!

## ⚡ قابلیت ها
- **🗣️ گفت‌وگوی صوتی فارسی:** صدای شما رو به متن تبدیل می‌کنه و پاسخ رو با صوت پخش می‌کنه.
- **💬 صفحه چت متنی:** علاوه بر صوت، یک رابط چت هم برای گفت‌وگوی متنی داره.
- **🔗 اتصال به APIهای مختلف:** می‌تونید اون رو به سرویس‌های هوش مصنوعی دلخواه وصل کنید.
- **🔌 حالت آفلاین:** امکان استفاده بدون نیاز به اینترنت.
